# English Training Game

Mini game interativo para treino de inglês com:
- Prepositions
- Business English
- Phrasal Verbs
- Filtros por nível: A2, B1, B2, C1
- Pontuação
- Explicação de erros
- Resumo da rodada

## Como rodar localmente

1. Instale o Node.js.
2. Abra a pasta do projeto no terminal.
3. Rode:

```bash
npm install
npm run dev
```

## Como publicar

### Netlify
1. Faça login no Netlify.
2. Arraste a pasta do projeto ou conecte com GitHub.
3. Build command: `npm run build`
4. Publish directory: `dist`

### Vercel
1. Importe o projeto.
2. Framework: Vite.
3. Build command: `npm run build`
4. Output directory: `dist`
